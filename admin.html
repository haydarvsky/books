الاتصال بـGitHub

غير متصل
كيف أُنشئ رمز الوصول؟ (مرة واحدة فقط)
  1. افتح github.com/settings/personal-access-tokens/new (رمز دقيق الصلاحيات — Fine-grained).
  2. الاسم: books-gallery · المدة: اختر أطول مدة (أو بلا انتهاء).
  3. Repository access: «Only select repositories» ← اختر books.
  4. Permissions ← Repository permissions ← Contents: Read and write. (لا حاجة لغيرها.)
  5. اضغط Generate token وانسخه هنا. يُحفظ في متصفحك هذا فقط ولا يُرسل إلا إلى GitHub.

يصلح أيضًا الرمز الكلاسيكي (ghp_…) بصلاحية repo.
