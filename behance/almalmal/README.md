# محتوى بيهانس — «الململ»

عرضٌ تقديميّ لعمل **تصميم الغلاف والتنضيد الداخلي** لكتاب «الململ» — خالد سالم السدّاني.

## المحتويات

| الملف | الوصف |
|---|---|
| `CONTENT-AR.md` | نصُّ بيهانس كاملاً: العنوان والوصف والوسوم، وكتل النصّ مرتّبةً بين الصور. |
| `slides/` | ١٣ صورة عرض بعرض ١٤٠٠ بكسل (مُصدَّرة ٢×، أي ٢٨٠٠ بكسل فعليّاً) — JPEG. |
| `_src/` | مصادر التوليد: يُعاد بناء الصور منها في أيّ وقت. |

نص ← صورة ← نص ← صورة … بالترتيب المذكور في `CONTENT-AR.md`.

## الهويّة المستخدمة

مأخوذة من `css/gallery.css` في هذا المستودع نفسه:

- الخط: **صقّال سعد** (`fonts/sakkal-400.woff2` و`sakkal-700.woff2`) — مُضمَّن Base64 داخل الصفحة.
- الأرضيّة `#141009` · الذهبيّ `#D9A441` · الكريميّ `#E8DFCC` · الورقيّ `#FAF6EF`
- لون العمل في الرفّ `#B1A068` (من `data/books.json`).

## القياسات

الأرقام المذكورة في الشرائح ٠٤ و٠٨ و١٢ ليست تقديريّة؛ قِيست من ملفّات الكتاب نفسها
بتحليل بكسلات الصور (`_src/measure-cover.js` و`_src/measure-pages.js`).

## إعادة التوليد

```bash
npm i playwright            # مرّة واحدة
cd behance/almalmal/_src
node build-slides.js        # يبني slides.html
node render-slides.js       # يصوّر الشرائح إلى ../slides/
```

لعملٍ آخر: غيّر `B` و`P()` في أعلى `build-slides.js` إلى معرّف الكتاب المطلوب في `images/`.
