# معرض أعمالي في الكتب — حيدر

رفّ كتبٍ تفاعلي ثلاثي الأبعاد يعرض أعمال تصميم الأغلفة والتنضيد الداخلي.

- **المعرض:** `index.html` — الرفّ يتحرك مع الفأرة، والوقوف على كتابٍ يُخرجه ويعرض عنوانه، والنقر يفتح نافذة العمل: الغلاف ثلاثي الأبعاد (أمامي/كعب/خلفي/مسطّح + تكبير) و/أو التنضيد الداخلي (كتاب مفتوح يُقلَّب صفحةً صفحة + تكبير).
- **لوحة التحكم:** `admin.html` — إضافة الكتب وتعديلها وحذفها وترتيبها؛ تُضغط الصور في المتصفح ثم تُنشر إلى هذا المستودع مباشرةً عبر GitHub API (التزامٌ واحد لكل عملية) برمز وصولٍ يحفظه المتصفح محليًّا.
- **البيانات:** `data/books.json` والصور في `images/<id>/`.
- **معاينة تجريبية:** `index.html?demo=1` (كتب وهمية مولّدة على الكانفاس)، و`admin.html?mock=1` (لوحة بلا نشر).

يُستضاف على GitHub Pages من فرع `main`.
